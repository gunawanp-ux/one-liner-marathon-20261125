One one-line comedy joke, up to 280 characters, for the make.fun
competition [One-Liner Marathon](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2).

## The joke

> My therapist said I use humor to avoid my feelings, so I laughed and asked if she takes Venmo.

## How it works

`main.py` writes the joke as exactly one line to `/output/entry.txt`,
the file the competition harness grades (UTF-8, 1–280 characters).
Nothing is printed to stdout.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
